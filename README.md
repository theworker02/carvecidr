# carvecidr

Carve host/cidr network string helpers for config audits.

**Site:** https://theworker02.github.io/carvecidr/

## Install / run

```bash
git clone https://github.com/theworker02/carvecidr.git
cd carvecidr
node src/cli.js
node --test
```
